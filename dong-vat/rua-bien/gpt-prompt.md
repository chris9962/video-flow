- No on-screen text.

Output exactly this:
1. A table with one row per scene: Scene id (M, A, B, C, D, E, F, G), what the viewer sees (start frame → end frame, 1–2 sentences, purely visual), English narration line for that scene, word count, Vietnamese translation of the line.
